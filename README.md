# InternSavy — Web Design Practice

A small front-end practice repository containing a portfolio page and a login-form page with supporting image assets.

## Contents

- `portfolio/` — portfolio/landing-page practice
- `Login Form/` — login-form practice
- Static image assets used by the pages

## Technology

- HTML5
- CSS3
- Browser-native rendering

## Run locally

1. Clone or download the repository.
2. Open the HTML page inside `portfolio/` or `Login Form/` in a web browser.
3. Keep referenced image files in their current relative locations.

No build step or backend is included.

## Notes

The login form should be treated as a UI demonstration only. It does not provide secure authentication unless a trusted backend, server-side validation, session handling, and password hashing are implemented.
